🐉 ボスバトルシステム
ボス召喚 コマンドでボスが出現し、視聴者全員のコメントが攻撃になります。HP指定：ボス召喚:500（上限2000）。
ボスサイズはHPに比例（HP100→約120px・HP2000→約420px）。
攻撃を受けるたびにランダムなセリフを表示。反撃確率は管理パネルで設定可（デフォルト20%・全キャラに5ダメ）。
撃破で全員 HP+20回復＋ランダム装備が全キャラに配布。次のボスは一定時間後に自動召喚されます。
ボス画像は public/chara/ の画像からランダム選択。管理パネルの「揺れ設定」でボスにも胸の揺れアニメーションを適用できます。
⭐ キャラ育成（レベル・EXP）
コメントするたびにEXPが1増え、レベルが上がります。最大レベルは100（合計4000コメントで到達）。
ATK = 1 + レベル（Lv.5 → ATK6）。HP = 30 + (Lv-1)×2（Lv.1→30HP, Lv.100→228HP）。レベルアップ時にバナー演出と効果音が鳴ります。

⚔️ 装備システム
ボス撃破で全キャラにランダムな装備が1つ配布されます。同じ種類が当たると合成（上限+10）。
ボスのHPが高いほど高レア装備が出やすくなります。
種類：剣⚔️・指輪💍・杖🪄・弓🏹（ATK+）　盾🛡️・兜⛑️・鎧🔰・首飾り📿（HP+）
ノーマル +1〜2 レア +3〜4 エピック +5〜6 伝説 +7〜8 神話 +9〜10
📊 キャラステータス
HP：基本30 ＋ HP系装備ボーナス（鉄壁ペットで+10追加）
MP：コメント攻撃で+1（ペット効果で+2〜+4）。上限なし。死亡しても保持。
　消費：ペットガチャ -20 ／ 出して（AI画像） -20 ／ スロット -3 ／ 回復 -2
ATK：1 ＋ レベル ＋ ATK系装備ボーナス ＋ 称号ボーナス
CRT（クリティカル率）：基本15%。ペット「偵察」+5%・「鋭爪」+20%（pet1・pet2それぞれ加算）＋ 称号ボーナス。クリ時ダメージ×2〜4倍。
キャラ名表示：設定した文字色・背景色・フォント・装飾がキャラ名にも反映されます。
💀 キャラ死亡・復活
ボスの反撃でHPが0になるとKO状態になり、2秒後に自動復活します。
死亡時：Lv・EXPがリセットされます。装備・MPはそのまま保持されます。
不死鳥ペットを持つキャラは1度だけHP50%で復活します。
💚 回復（MPスキル）
コメントに 回復 を含めると、MP2を消費して全キャラHP+2回復します。
MPが2未満の場合は失敗します。回復中もボスへの攻撃は発動します。
MP 20/20（最大）
🐾 ペットシステム
コメントに ペットガチャ と入力すると MP20を消費 してペットを1体引けます。
ペットはキャラクターの右下に常時表示され、様々なバトル効果を発揮します。
ペットも攻撃モーションを行い（キャラの後に順番に）、ダメージ数字も表示されます。
新たにガチャを引くと対象スロットのペットは上書きされます。ノーマル〜神話の5段階レアリティ。
ガチャ20回到達で2枠目が解放され、20回目以降は奇数回→1枠目・偶数回→2枠目に交互格納。2体同時所持で称号「二刀の獣使い」が解除されます。
📝 Wordleゲーム
5文字のカタカナ単語を当てるゲームが常時画面に表示されます（text/wordle.txt から出題）。
視聴者がカタカナ5文字をコメントすると自動で推測として判定されます。
🟩＝正解位置、🟨＝文字が含まれる、⬜＝含まれない。
正解した視聴者はHP全回復＋正解回数がカウントされます。
⚡ 早押しゲーム
⚡ 早押しボタンで手動起動。配信開始後も一定間隔で自動起動します（間隔は管理パネルで調整可）。
白ストリーム：テロップがニコニコ動画風に右から左へ流れる。正解でHP+10回復。
赤ストリーム：赤背景の緊急テロップ。白の3倍間隔で発生。正解でHP+15回復。
どちらも30秒で時間切れ。正解回数は称号解除に使用されます。
🎲 キャラのランダム初期設定
各キャラが初めてステージに登場するとき、吹き出しの形・フォント・装飾・文字色・大きさ（50〜60px）がランダムに設定されます。
これらは後からコマンドで上書きできます。コメントの吹き出しはタイプライター演出で表示されます。
🔊 戦闘音声
public/sound/sentou/ フォルダに音声ファイルを入れると、ボスへの攻撃時・ボスの反撃時にランダムで再生されます。
対応形式：wav / mp3 / ogg / m4a / aac / flac
📈 ダメージランキング
ボスを撃破するとそのボスへの合計ダメージ上位5名のランキングが表示されます。
ランキングパネルはドラッグで移動できます。位置はブラウザに保存されます。
🎨 AI画像生成（出してコマンド）
コメントに 出して / 出ろ / 生成 を含めると MP20を消費 してStable DiffusionでAI画像を生成します。
MPが20未満の場合は「MPが足りなくて画像生成できません」と吹き出しに表示されます。
コメントのテキスト部分がそのままプロンプトになります。Discord Webhook連携時は生成画像とプロンプトが自動送信されます。
⚔️ タイマン（1v1 決闘）
タイマン:相手名 または ランダムタイマン で他のキャラに1v1決闘を申し込みます。
申し込まれた側は次のコメントで自動参加。お互いのATK・装備・ペット・称号を総合判定して勝敗決定。
勝者は敗者のMP全額を奪取。ただし挑戦者がレベルで上回っている場合、1Lv差ごとに奪えるMP量が5%ずつ減少します（レベル差20以上で0%）。
クールダウンはデフォルト5分（管理パネルで変更可）。敗北時コマンドも管理パネルで設定可能。
🎰 スロット
スロット でMP3消費して1回。スロット開始 で自動連続（スロット停止 で停止）。
3リールが揃うと当たり。絵柄と報酬（デフォルト値）：
🍒 チェリー 20%→MP+5 ／ 🔔 ベル 10%→MP+10 ／ ⭐ スター 5%→MP+25
💎 ダイヤ 1%→MP+60 ／ 7️⃣ JACKPOT 0.5%→MP+200 ／ ハズレ 63.5%
確率・報酬は管理パネルからカスタマイズ可。
📦 宝箱システム
配信中5分ごとに自動でステージに宝箱が出現します（出現から20秒間有効）。
出現中に 開ける とコメントした先着1名が中身を取得。
中身はエピック以上確定の装備（+5〜+10）＋HP+30回復。花火・紙吹雪・ハートシャワーの豪華演出あり。
開けた回数は記録され、称号解除（宝探し・宝箱ハンター・財宝の王 など）に使用されます。
🏇 競馬システム
馬が自動でレースを走ります。ベット期間中に 馬券 馬番 賭けMP でベット（例：馬券 3 10）。
複勝（2着以内）は範囲指定：馬券 2-5 10。
レース中にコメントに馬番の数字が含まれると応援になり、その馬がわずかに加速します。
的中すると賭けMPに応じたオッズでMPが返ってきます。
😴 自動 AFK・離席表示・自動削除
30分間コメントがないキャラは自動でAFK状態になります（透明度・グレースケール・明度は管理パネルで調整可）。
コメントに AFK / ＡＦＫ を含めると即時AFK。放置:テキスト / 無明:テキスト でカスタムメッセージ付き離席。
次にコメントすると自動で復帰します。
30分間コメントがないキャラは自動でステージから削除されます（セーブデータは保持されるため、次回コメント時に復元）。
ただし 手動でAFK・放置・無明コマンドを入力したキャラは自動削除の対象外です。masterキャラも対象外。
🌸 アゲルちゃん会話モード
配信中にリアルタイムで視聴者コメントに返答するAIキャラ「星井野アゲル」を呼び出せます。
Ollamaによる感情・好感度付き返答、VOICEVOX読み上げ、SD画像生成（自撮り）、YouTube再生、BGMループに対応。
詳細は 🌸 アゲルちゃん セクションを参照。

管理パネルで Discord Webhook URL を設定すると、ステータス確認 時にスクリーンショットを自動投稿します。
Ollama（ローカルAI）が起動中なら、キャラの状態を元にした総評コメントを生成して添付します（9秒タイムアウト。時間内に返答がなければ総評なしで投稿）。
AI画像生成（出して） と ai:質問 コマンドも Ollama を経由して動作します。
🔊 TTS / AI / ノベル
tts:テキスト：テキストを音声合成（TTS）で読み上げます。
ai:質問 / AI:質問：Ollama に質問。回答が吹き出しとコメントログに表示されます。
