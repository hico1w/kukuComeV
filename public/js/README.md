# app.js 分割ファイル索引

元の単一ファイル `public/app.js`（約14,900行）を、**機能単位で連続行のまま13分割**したもの。

## 重要な前提
- **読み込み順は番号順を厳守**（`index.html` の `<script>` 順）。元ファイルの出現順＝実行順を保持している。
- 全ファイルは**同一のグローバルスコープを共有**する classic script。関数・変数・コマンドの挙動は単一ファイル時と完全に同一。
- 分割は「行の切り出し」のみでロジック変更なし。13ファイルを番号順に連結すると、分割前の `app.js`（git履歴 v2.715 時点）と**バイト単位で一致**する。

## 編集時の注意
- 関数を別ファイルに移動する場合、トップレベルの `const`/`let` は宣言順（TDZ）に依存しうるため、**実行順が変わらないよう**注意する。
- 新しいファイルを足したら `index.html` の `<script>` リストに**正しい順序で**追加すること。
