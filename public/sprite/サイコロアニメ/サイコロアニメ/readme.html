サイコロアニメ

●収録内容

サイコロが振られるアニメーション素材です

各クリエイター支援サイトの無料プラン向けにアップした素材から、ブログ用にサイズとバリエーションを限定しています

【友達プラン】2019年8月サイコロアニメ素材セット - ぴぽやフレンズ (ぴぽ)の投稿｜ファンティア[Fantia]

【友達プラン】2019年8月サイコロアニメ素材セット - ぴぽや - Ci-en

FANBOXは無料プランが作れない仕様のため割愛しています

アニメパターンをスプライトシート状に並べたPNG画像となっています

アニメーションの表示速度は15fpsで作成されています

ファイルサイズの最適化はしておりませんので、必要に応じて下記の「注意事項」で紹介しているアプリなどでファイルサイズを小さくすることをお奨めします
