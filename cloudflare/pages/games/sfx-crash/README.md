# AGERU CRASH!! に必要な効果音

`cloudflare/pages/games/crash.html` が `./sfx-crash/<キー>.mp3` を読む。
**1つも無くても無音で普通に遊べる**（読めなかった音は黙って鳴らないだけ）ので、用意できたものから順に置けばよい。
キー名がそのままファイル名。**`<キー>.mp3` を優先して読み、無ければ `<キー>.wav` を使う。**
`SFX_LIST` に `pref:'.wav'` と書いたキーだけ**逆（wav 優先）**になる。両方無いキーは黙って鳴らないだけ。

## 音量のそろえ方（重要）

`SFX_LIST` の各行が2つの数を持つ。

| | 意味 |
|---|---|
| `v` | **ミックス上の相対的な大きさ**。演出としてどれくらい目立たせたいか（例: `crash` .9 / `bound` .6） |
| `r` | **素材の実測ラウドネス**。300ms 窓の最大 RMS を Web Audio でデコードして計測した値 |

実際に鳴る音量は **`gain = v * SFX_TGT / r`**（`SFX_TGT = 0.22`）。
`r` で割ることで素材の大小が相殺され、**どの素材を入れても `v` どおりの比率で鳴る**。

### Web Audio は使わない（重要な制約）

音量は **`HTMLAudioElement.volume` だけ**で決めている。`AudioContext` / `GainNode` は使っていない。

> **理由**: `createMediaElementSource()` は `file://` で開いたページだと素材を別オリジン扱いにして、
> **出力が完全な無音になる**。実測で http 配信なら出力ピーク 0.297、同じコードを file:// で開くと **0.000**。
> ローカルで HTML を直接開いて確認することがあるので、この経路には依存できない。

**その代わり `volume` の上限が 1 なので、`gain` が 1 を超える素材は使えない。**
1 を超えていた3つは**素材側を正規化**して `r` を `.22` にそろえてある。

| キー | 元 | 正規化 | 現在のファイル |
|---|---|---|---|
| `click` | `click.mp3` r=.074（gain 1.49） | ×2.98 | **`click.wav`**（`pref:'.wav'`） |
| `tame` | `tame.mp3` r=.033（gain 4.00） | ×6.60 | **`tame.wav`**（`pref:'.wav'`） |
| `stop` | `stop.wav` r=.083（gain 1.86） | ×2.65 | `stop.wav`（上書き） |

- **`click.mp3` / `tame.mp3` は消していない。** mp3 を再エンコードする手段（ffmpeg / lame / sox）がこの環境に無いため、
  デコードして正規化した **wav を別に書き出し**、`pref:'.wav'` でそちらを読ませている。元の mp3 はそのまま残してある。
- `wind` だけは 104秒の mp3 で wav 化するとサイズが大きすぎるため正規化していない。
  代わりに `v` を `.33` にして、最高速でも `gain` が 1.008（＝実質 1.0 で頭打ち）に収まるようにしてある。
- `click.cc0.wav` は差し替え前の CC0 のクリック音。使われていないが予備として残してある。

### 素材を差し替えたら

1. 新しい素材の `r`（300ms 窓の最大 RMS）を測る。`decodeAudioData` → モノラル化 → 移動RMSの最大値。ffmpeg 等は不要
2. `SFX_LIST` の `r` を書き換える
3. `gain = v * .22 / r` が **1 を超えるなら素材側を正規化**して `r` を `.22` にそろえる（超えないならそのままでよい）

## 全体音量

画面右上の **♪ SOUND の横のスライダー**で 0〜100% を調節できる（既定 50%）。
`localStorage` の `crash-vol` に保存され、次回も同じ音量で始まる。ON/OFF は `crash-snd`。
`applyVol()` が `gain * masterVol` を各要素の `volume` に入れるので、効果音・ループ音・BGM すべてに効く。
スライダーを動かすと、**いま鳴っているループ音と BGM にはその場で反映**され、単発音は次に鳴るときから反映される。

## ボイス（`hit/`）

効果音とは**別レイヤー**で、`hit/` 以下のファイルから1つランダムに鳴らす。

| フォルダ | 鳴るタイミング | 点数 |
|---|---|---|
| `hit/` | **地面以外（キャラ）に当たったとき**（`onHit()`） | 11 |
| `hit/diveArial/` | **エアリアル／ダイブを撃ったとき**（`aerial()` / `dive()`） | 4 |
| `hit/over/` | **ゲームオーバー**（`gameOver()`） | 5 |

- **ボイス同士は重ねない（1ch）。** 連続ヒットで重なると何を言っているか分からなくなるため、
  新しいボイスが鳴るときに前のボイスを止める。効果音・BGM とは重なる
- **直前と同じファイルは選ばない**（`g.last`）
- 選択は `Math.random()`。**地形の抽選に使っている `rnd()` は消費しない**
  （消費するとステージ構成が変わってしまうため）
- 音量は `VOICE` の `v`（現在 **0.85**）。全体音量スライダーも効く

### ファイルを足すとき

静的サイトなのでフォルダを列挙できない。**`crash.html` の `VOICE` の `files` 配列にファイル名を足すこと。**
音量も `r = .22` にそろえてから置く（下の「素材を差し替えたら」と同じ手順）。
**全20点は正規化済み**（元は r=0.044〜0.271 の6倍差 → 0.219〜0.220）。
正規化前の原本は `assets/crash/voice-orig/` に置いてある。
`「えい！」.mp3` `「ドン！」.mp3` はデコードして `.wav` を書き出したもので、**元の mp3 も残してある**。

## 今入っている音の出典

自前の音が無いキーは、以下の **CC0（パブリックドメイン）** 素材を割り当ててある。差し替えたい場合は
同じキー名の mp3 を置けば、そちらが優先される（wav を消す必要はない）。

- **8-Bit Sound Effect Pack Vol.001**（@Shades / CC0） — OpenGameArt
  `crash` `hit_slow` `block` `chance` `special` `ageru_special` `boss_fail` `aerial` `dive` `slam` `bound` `revive` `stop` `record`
  <https://opengameart.org/content/8-bit-sound-effect-pack-vol-001>
- **`wind` / `roll`**（ループ音）は合成して生成。一回モノをループさせると継ぎ目で音が途切れるため、
  端をクロスフェードしたノイズを2秒ぶん作っている

## BGM

`アゲル CRASH!!.mp3` を**発射と同時にループ再生し、ゲームオーバーで停止**する。
ファイル名は固定で、コード側の `BGM_FILE` で指定している。音量は効果音と同じ基準
（`BGM_GAIN = .42 * SFX_TGT / .145` ＝ 0.637）でそろえてある。

- 単発の音は**短く**（0.1〜0.8秒程度）。長いと連続ヒット時に重なって濁る。
- **素材そのものはノーマライズして最大音量で作ってよい。** 大きすぎても `r` で相殺される（小さすぎる方が困る）。
- `loop` と書いてある3つだけ**ループ再生**。途切れずループする素材にすること。

## 差し替え・追加

キーを増やしたいときは `crash.html` の `SFX_LIST` に1行足すだけ（`{ v:大きさ, r:実測値, desc:'説明' }`、
ループなら `loop:true`、wav を優先したいなら `pref:'.wav'`）。
鳴らすのは `se('キー')`、ループは `seLoop('キー', ミックス値)`。
`r` が分からないうちは `SFX_TGT` と同じ `.22` を入れておけば等倍で鳴る。
