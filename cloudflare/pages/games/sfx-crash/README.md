# AGERU CRASH!! に必要な効果音

`cloudflare/pages/games/crash.html` が `./sfx-crash/<キー>.mp3` を読む。
**1つも無くても無音で普通に遊べる**（読めなかった音は黙って鳴らないだけ）ので、用意できたものから順に置けばよい。
キー名がそのままファイル名。形式は **mp3**。

- 単発の音は**短く**（0.1〜0.8秒程度）。長いと連続ヒット時に重なって濁る。
- 音量はコード側で調整済み（下表の「音量」）。素材そのものは**ノーマライズして最大音量**で作ってよい。
- `loop` と書いてある2つだけ**ループ再生**。途切れずループする素材にすること。
- 画面右上の「♪ SOUND」ボタンで全体のON/OFFができる（設定は localStorage に保存）。

## 差し替え・追加

キーを増やしたいときは `crash.html` の `SFX_LIST` に1行足すだけ（`{ v:音量, desc:'説明' }`、ループなら `loop:true`）。
鳴らすのは `se('キー')`、ループは `seLoop('キー', 音量)`。
