# AGERU CRASH!! に必要な画像

`cloudflare/pages/games/crash.html` が `./img-crash/<キー>.webp` を読む。
**1枚も無くてもプレースホルダ（色付きの枠＋名前）が描かれて遊べる**ので、用意できたものから順に置けばよい。
キー名はそのままファイル名。形式は `.webp`（透過あり推奨）。

サイズは「これくらいで描いてくれれば破綻しない」という目安。
ゲーム側は**高さ基準で縦横比を保って描画**するので、多少違っても問題ない。

## 自機・飛ぶ側（必須度：高）

| ファイル | 推奨サイズ | 内容 |
|---|---|---|
| `ageru_bike.webp` | 340×300 | 自転車に乗って突っ込む体勢のアゲル。**右向き**。発射前の待機・激突で使う |
| `ageru_kick.webp` | 300×300 | エアリアル（飛び蹴りで上に打ち上げる）アゲル。右向き・斜め上に蹴る感じ |
| `ageru_dive.webp` | 300×300 | ダイブ（上から叩き落とす）アゲル。右向き・斜め下に叩きつける感じ |
| `hico_fly.webp` | 220×220 | 吹っ飛んでいるヒコ。**画面内で回転させる**ので、中心が体の真ん中に来るように |
| `hico_down.webp` | 260×160 | 止まってダウンしているヒコ。地面に伏せた横向き。リザルトで表示 |

## 当たるキャラ（バンパー）

透過必須。立ち絵をそのまま出すので**右向き／正面**どちらでも可。

| ファイル | 推奨サイズ | ゲーム内の役割 |
|---|---|---|
| `c_baby.webp`  | 220×260 | ベビーアゲル — 斜め45度に打ち上げ |
| `c_goth.webp`  | 220×280 | ゴスアゲル — 高い角度に打ち上げ |
| `c_denpa.webp` | 220×280 | デンパアゲル — 低い角度に加速 |
| `c_boss.webp`  | 320×360 | ボスアゲル — 当たると即終了（0.7秒以内クリックで大逆転）。**でかく・危険な見た目で** |
| `c_robo.webp`  | 220×260 | ヨクネロボ — ブロック（次のアゲル系の効果を消す） |
| `c_kani.webp`  | 240×160 | カニ — 角度を変える |
| `c_hugu.webp`  | 220×200 | フグ — 減速させる |
| `c_neko.webp`  | 200×200 | キショネコ — 小さく打ち上げ |

## 背景（無い場合はグラデーションで代用される）

| ファイル | 推奨サイズ | 内容 |
|---|---|---|
| `bg_sky.webp`  | 1200×600 | 空。**1枚で画面全体に引き伸ばす**ので、高さ方向にグラデーションしているもの。無い場合は高度で色が変わる自動グラデーション（高く飛ぶと星空になる）が使われる |
| `bg_far.webp`  | 1600×420 | 遠景（山・ビル影など）。**左右がつながるループ画像**にすること |
| `bg_near.webp` | 1600×300 | 近景（木・建物など）。同じく**左右ループ**。遠景より速く流れる |
| `ground.webp`  | 600×160  | 地面のタイル。**左右ループ**。上端が地面の表面になる |

## タイトルロゴ（任意）

| ファイル | 推奨サイズ | 内容 |
|---|---|---|
| `logo.webp` | 900×300 | タイトル画面のロゴ。置くと `AGERU CRASH!!` のテキストの代わりに表示される |

## ゲーム一覧のサムネイル（`cloudflare/pages/img-games/` に置く）

一覧カード用。**無い場合はグラデーション＋頭文字**のカードになる。

| ファイル | 推奨サイズ | 内容 |
|---|---|---|
| `img-games/crash.webp` | 640×400 | AGERU CRASH!! のサムネ（16:10） |
| `img-games/dino.webp`  | 640×400 | DINO のサムネ（16:10） |

置いたら `cloudflare/` で `npx wrangler pages deploy pages --project-name=kukucome-chara --branch=main`
（詳しくは `.claude/commands/deploy-pages.md` = `/deploy-pages`）。
