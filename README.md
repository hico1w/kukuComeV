# kukuCome 🎮

**kukuLIVE** のコメントをリアルタイムで表示するキャラクタービジュアライザーです。
視聴者がコメントでキャラクターを召喚・カスタマイズし、ステージ上でアニメーションします。
OBS のブラウザソース＋クロマキーで配信画面に重ねて使用できます。

---

## 機能

- **コメントでキャラ召喚** — `キャラ1`〜`キャラ500` または自由なエイリアスで登場
- **カスタム画像** — `public/chara/` に画像を置いてキャラに割り当て可能
- **吹き出し** — テキスト・画像・ボイスコメント・エモーションに対応
- **アニメーション** — 呼吸・ジャンプ・バウンス・初コメ振動
- **ドラッグ移動** — ステージ上のキャラをマウスでつかんで移動
- **フォント / 文字色 / 吹き出し形状** をコメントでカスタマイズ
- **OBS グリーンバック対応** — 背景色をピッカーで自由に変更

---

## 必要環境

- [Node.js](https://nodejs.org/) 18 以上
- [kukuLIVE](https://live.erinn.biz/) アカウントと API キー

---

## セットアップ

```bash
git clone https://github.com/hico1w/kukuCome.git
cd kukuCome
npm install
npm start
```

ブラウザで **http://localhost:3000** を開く。

---

## 使い方

1. [APIキー取得ページ](https://live.erinn.biz/login.php?action=getAPIKey) で API キーを取得
2. 画面上部の「APIキー」欄に入力
3. 「▶ 開始」ボタンを押す（配信番号は空欄で自動取得）
4. 視聴者が `キャラ1` などとコメントするとキャラが登場

詳しいコマンドは画面右上の **❓ コマンド一覧** から確認できます。

---

## キャラ画像のカスタマイズ

1. `public/chara/` フォルダに PNG / JPG / GIF / WebP / SVG を置く
2. 「🖼 キャラ画像」ボタンを押す
3. 各キャラのプルダウンから画像を選択
4. エイリアス欄に好きな文字列を入力 → 視聴者がその文字列でコメントするとキャラ変更

---

## OBS での使用方法

1. OBS に **ブラウザソース** を追加: `http://localhost:3000`
2. 幅・高さを配信解像度に合わせる（例: 1920×1080）
3. **カラーキーフィルタ** を追加してグリーン（`#00FF00`）を除去
4. アプリの「BG」ピッカーで背景色を OBS のキー色に合わせる

## 主なコマンド一覧

| コマンド | 内容 |
|---|---|
| `キャラN`（1〜500） | キャラを設定して登場 |
| `名前:たろう` | 表示名を変更（永続） |
| `色:赤` | 文字色を変更（永続）|
| `吹き出し:丸` | 吹き出し形状を変更（永続） |
| `移動:速い` | ランダム移動（永続） |
| `上:100` / `右:50` | 方向移動、複数指定で順番に実行 |
| `大きさ:大` | キャラサイズ変更（永続） |
| `はずむ` | 音楽バウンスアニメーション（永続、`移動:止まれ` で停止） |
| `フォント:メイリオ` | フォント変更（永続） |
| `文字サイズ:大` | 文字サイズ変更（そのコメントのみ） |
| `太字` / `斜体` | 書体変更（そのコメントのみ） |

詳細・フォント一覧は **[コマンド一覧ページ](/help.html)** を参照。
